# Assigned face morph

Educational morph of two reference photographs assigned by IITM TDS GA3. This is a synthetic transition, not footage of a real event.

- Start: Kemi Badenoch, © House of Commons / Roger Harris, 15 July 2024. [Wikimedia Commons source](https://commons.wikimedia.org/wiki/File:Official_portrait_of_Kemi_Badenoch_MP_crop_2,_2024.jpg), [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).
- End: Mickey Rooney, studio publicity portrait, circa 1940. [Wikimedia Commons source](https://commons.wikimedia.org/wiki/File:Mickey_Rooney_still.jpg), public domain per the source record.

Changes: cropped and eye-aligned photographs; facial geometry interpolated using MediaPipe landmarks, triangular affine warps, eased blending and endpoint holds. Attribution is also embedded in the MP4 metadata. No endorsement is implied.
